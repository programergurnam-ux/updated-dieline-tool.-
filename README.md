# Packaging Dieline Tool - Latest Updates 📦✨

Welcome to the **Packaging Dieline Tool** repository! This application is designed to automatically generate and customize packaging box dielines for print and production workflows.

---

## What's New in This Update?

We have introduced several key structural and design enhancements for **Carton Box Dielines**:

### 1. 📐 Rounded Top & Bottom Flaps
- Added rounded corners/radii for top and bottom closing flaps to improve structural aesthetic and prevent tearing during box closure.
- **Diameter / Radius Controls:** Added user inputs to precisely define and adjust the flap corner diameters/radii according to custom package specifications.

### 2. ⚡ Double Crease Lines (Double Band Crease)
- Integrated **Double Band Crease** support on major fold joints.
- Allows better folding flexibility for thicker carton boards, preventing material cracking and ensuring smooth box assembly.

---

## 🛠️ Features Summary
- **Custom Dimensions:** Define precise box parameters (Length, Width, Height, Flap allowances).
- **Advanced Flap Customization:** Adjust flap rounding diameter and double-crease offsets.
- **Production-Ready Output:** Clean line types for Outer Cut, Inner Crease, and Bleed boundaries.
